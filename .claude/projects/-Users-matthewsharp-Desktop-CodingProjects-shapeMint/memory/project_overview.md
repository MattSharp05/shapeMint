type: project
---

ShapeMint lets users generate 3D models from text/image prompts via Meshy AI, then order physical prints from multiple vendors (Slant3D, Shapeways, Treatstock, CraftCloud). Key workflows: text/image-to-3D generation with polling, thumbnail auto-generation, multi-vendor quote comparison, and order fulfillment.

**Why:** Platform aims to bridge AI-generated 3D content with physical manufacturing.
**How to apply:** Features span the full pipeline from generation to delivery — changes often touch services, types, and UI together.
